**Engenheiro de Software | Desenvolvedor Backend & Fullstack**

Sou um desenvolvedor focado na construção de aplicações escaláveis, seguras e de alta performance. Meu objetivo não é apenas escrever código, é arquitetar soluções que resolvem problemas reais de negócio. Atuo fortemente com o **Ecossistema Java**, entregando desde a segurança da API até a infraestrutura de deploy.

---

### 🚀 O Valor que Eu Entrego

- 🏗️ **Arquitetura e Escala:** Construção de APIs RESTful robustas e implementação de **WebSockets** para colaboração simultânea em tempo real.
- 🔐 **Segurança Absoluta:** Proteção de endpoints e dados sensíveis utilizando **Spring Security**, criptografia avançada com **Bcrypt** e autenticação estruturada (JWT).
- ⚙️ **Processamento Assíncrono e Performance:** Desacoplamento de tarefas pesadas (como formatação e geração de PDFs) utilizando mensageria com **RabbitMQ**. Otimização drástica de tempo de resposta com sistemas de cache usando **Redis**.
- 🚀 **Qualidade e DevOps:** Controle absoluto do banco de dados com migrations via **Flyway**, testes unitários com **JUnit**, e entregas contínuas automatizadas via **GitHub Actions** em ambientes conteinerizados com **Docker**. 
- 📊 **Visão de Futuro:** Planejamento de métricas e observabilidade contínua utilizando **Grafana e Prometheus**.
- 📍 Baseado em São Paulo, Brasil.
